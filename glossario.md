# 8 conceitos fundamentais do Git e GitHub
## 1. Git

É um sistema de controle de versões que permite acompanhar as alterações feitas nos arquivos de um projeto e voltar para versões anteriores quando necessário.

## 2. GitHub

É uma plataforma online onde podemos armazenar projetos, compartilhar códigos e trabalhar em equipe.

Diferença entre Git e GitHub: o Git é a ferramenta que controla as versões do projeto, enquanto o GitHub é a plataforma que permite hospedar e compartilhar esses projetos pela internet.

## 3. Repositório

É o local onde ficam armazenados os arquivos de um projeto e o histórico de todas as alterações realizadas nele.

## 4. Commit

É como um ponto de salvamento do projeto. Ele registra as mudanças feitas nos arquivos, acompanhado de uma mensagem explicando o que foi alterado.

Exemplo de mensagem: "Adiciona página inicial do site".

## 5. Branch

É uma ramificação do projeto que permite trabalhar em novas ideias ou funcionalidades sem modificar diretamente a versão principal.

## 6. Main

É o nome geralmente utilizado para identificar a branch principal do projeto, onde fica a versão considerada principal ou estável.

## 7. Merge

É o processo de juntar as alterações de uma branch com outra, incorporando o trabalho realizado ao projeto. Às vezes podem acontecer conflitos quando duas pessoas modificam a mesma parte ou linha de um arquivo, sendo necessário resolver as diferenças antes de concluir o merge.

## 8. Pull Request

É uma solicitação para que as alterações de uma branch sejam revisadas por outras pessoas antes de serem adicionadas à main. Durante essa revisão, os colegas podem comentar, sugerir melhorias e pedir correções. Depois da aprovação, pode ser feito o merge.
