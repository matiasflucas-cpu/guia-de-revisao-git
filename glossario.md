# 8 conceitos fundamentais do Git e GitHub
1. Git

É um sistema de controle de versões que permite acompanhar as alterações feitas em arquivos e projetos, além de possibilitar voltar a versões anteriores.

2. GitHub

É uma plataforma online que permite armazenar projetos, compartilhar códigos e trabalhar em equipe.

Diferença entre Git e GitHub: o Git é a ferramenta que controla as versões do projeto, enquanto o GitHub é o site que permite hospedar e compartilhar esses projetos pela internet.

3. Repositório

É o local onde ficam armazenados os arquivos de um projeto e o histórico de todas as alterações realizadas nele.

4. Commit

É como um ponto de salvamento do projeto. Ele registra as mudanças feitas nos arquivos, geralmente acompanhado de uma mensagem explicando o que foi alterado.

5. Branch

É uma ramificação do projeto que permite trabalhar em novas ideias ou funcionalidades sem modificar diretamente a versão principal.

6. Main

É o nome geralmente utilizado para identificar a branch principal do projeto, onde fica a versão considerada principal ou estável.

7. Merge

É o processo de juntar as alterações de uma branch com outra, incorporando o trabalho realizado ao projeto.

8. Pull Request

É uma solicitação feita para que as alterações de uma branch sejam analisadas e, se aprovadas, adicionadas a outra branch, geralmente a main.
